INDEPENDENT CREATION

New Strategies

These are not merely copies of one parent. EVE assembles valid combinations from six strategy families, schedules, regimes, direction logic and risk rules.

CONTROLLED MUTATION

Evolution

Each lineage has a frozen current champion. Children alter one controlled gene and are selected on validation data. Locked data can veto a child but is never used to invent it.

SURVIVORS ONLY

MT5 Packages

Only strategies that pass chronological testing, walk-forward stability, recent-regime checks and parameter-neighbour robustness appear here.
